# Install this GitHub profile

1. Open https://github.com/MohamedShiras/MohamedShiras. This must be the **public** repository whose name exactly matches your GitHub username.
2. Back up the current README, then upload the contents of this folder to the repository root. Keep the `.github` folder (enable viewing hidden files if needed).
3. Commit to the `main` branch.
4. Open the repository's **Settings → Actions → General → Workflow permissions** and select **Read and write permissions**. Save.
5. Open **Actions**, enable workflows if GitHub prompts you, then run **Generate contribution snake** and **Update profile stats card** once using **Run workflow**.
6. After the snake workflow completes, the `output` branch is created. The contribution snake image will then appear in the README.

## Notes
- GitHub profile README repository name must match the account username: `MohamedShiras`.
- The external stats, typing, streak and skill-icon services are third-party services and may occasionally be unavailable or rate-limited.
- The README links to the project repositories and URLs currently known. Check that each project repository is public and that its URL is correct before publishing.
- No personal access token is required; the workflows use GitHub's automatically provided `GITHUB_TOKEN`.
